# 好きから始める 入試英語 v1.9

## ファイル構成

- `index.html` — 画面構造
- `css/styles.css` — PC・スマートフォンの表示
- `js/data.js` — 動画、基本語句、追加学習バンク、例文
- `js/app.js` — Day切替、問題、音声再生、進捗保存

## 教材を増やす場所

基本教材と追加学習バンクは `js/data.js` にあります。語句には `term`, `meaning`, `sentence`, `jp` を揃えてください。起動時に例文抜けを検査し、開発者コンソールへ警告します。

## 起動

フォルダ構成を保ったまま `index.html` をブラウザで開いてください。ブラウザの制約で動作しない場合は、このフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000` を開いてください。


## v1.10 問題・回答監査

- 追加学習バンクの和訳選択問題で、選択肢シャッフル後の正解番号を再計算するよう修正。
- `stay in` の表示訳を「～にいる／とどまる」へ調整。
- 構文型（例: `protect A from B`）を例文へ文字列一致で穴埋めしていた生成問題を廃止。
- LISTENは「例文内で使われる表現の選択」、EXAMは「和訳から語句・構文を思い出す」形式へ変更。
- 起動時に全セットの選択肢、正解番号、語句、意味、例文、和訳を機械監査。
